# Plan Maker — Implementation Planning

Use this entry point for **Plan Maker**, **plan-maker**, **implementation plan**, **implementation planning**, **implementation-plan maker**, **PRD**, **product requirements document**, **architecture plan**, **technical plan**, **build plan** or **execution plan** for software work.

These names lead to the same AI-Verse planning method, not separate planning systems.

- [Planning method](ADAPTIVE-IMPLEMENTATION-PLANNING-SKILL.md): how to inspect existing code, choose the smallest complete change and plan proportional implementation.
- [Implementation plan / PRD / architecture template](IMPLEMENTATION-PLAN-TEMPLATE.md): a concise starting shape, expanded only where the work needs it.

When asked to make, improve or continue an implementation plan, read the method and use the template as needed. When asked for a specific existing plan, locate that plan instead of creating a replacement. Project instructions, source authority and current user authorization remain controlling; finding this entry does not authorize implementation or checks.

System owns the planning sources under `docs/`. A personal OS may keep synchronized copies under `knowledge/implementation-planning/`. Update the method/template together from the same source. This index contains discovery terms and links only.
