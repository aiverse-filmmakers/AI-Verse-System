## Frozen comparison scenarios

The evaluation used six predefined scenarios rather than selecting examples after seeing results:

1. operator rationale/explainability;
2. workspace next-action decision;
3. workspace prioritization;
4. workspace blocker/material-change awareness;
5. irrelevant formatting task;
6. Purpose-owner-unavailable strategic task.

Strategic with-Purpose and Purpose-absent comparison arms preserved the same ordinary owner context where technically fair.

## Measured strategic value

The initial same-state comparison recorded these predefined owner-backed decision-basis deltas:

| Scenario | Purpose reads | Decision-basis delta | Scope |
| --- | ---: | ---: | --- |
| operator rationale | 1 | +3 evidence classes | exact `operator` |
| workspace next action | 1 | +4 evidence classes | exact `workspace:alpha` |
| workspace prioritization | 1 | +5 evidence classes | exact `workspace:alpha` |
| workspace blocker awareness | 1 | +4 evidence classes | exact `workspace:alpha` |

The complete gate then confirmed that:

- all four strategic scenarios retained positive owner-backed decision value;
- next-action and prioritization improved independently;
- blocker awareness and rationale/explainability improved independently;
- unchanged owner state produced semantically stable Purpose projections across independent session/run IDs;
- repeated explanation could be reduced because the owner-backed Purpose projection remained available as stable strategic context.

The gate did not claim credentialed production-model output scoring. CI had no production-model evaluator, so the accepted value evidence remained the frozen owner-backed decision-basis methodology rather than fabricated model-quality scores.

## Anti-bloat measurements

The accepted anti-bloat result was:

- every relevant strategic scenario performed exactly **one** Purpose owner read;
- every admitted Purpose envelope remained within the hard **16,384-byte** Phase 7 runtime budget;
- the trivial deterministic formatting scenario performed exactly **zero** Purpose owner reads;
- the trivial scenario added exactly **zero** Purpose bytes;
- scope-noise review found **zero unrelated-scope refs/bytes** in admitted projections;
- Purpose relevance remained separate from ordinary history-depth behavior;
- Purpose-owner unavailability preserved ordinary context assembly and injected no stale substitute.

This proves that Purpose is relevance-gated rather than always-on.

## Isolation and authority result

The value gate also confirmed:

- no workspace-isolation regression;
- exact scope was preserved for strategic owner reads;
- no accepted Purpose projection contained another workspace's refs;
- projection authority remained `ai-verse-os`;
- Purpose remained a disposable projection and did not become a second truth store;
- fresh owner state continued to outrank cached UI/output state.

## Latency and cost measurement boundaries

Local context-assembly latency was measured using warmup plus repeated median fixture runs. Those local fixture measurements established that the tested runtime overhead was acceptable for the demonstrated value, but they are **not** represented as production network/provider latency.

Provider billing/cost was not measurable from Gateway context assembly and therefore remained `null` / unmeasured. It was not estimated and was not silently converted to a zero-cost claim.

Likewise, production-model output quality was not available as a credentialed CI measurement surface. The gate explicitly preserved that limitation.

## Why expansion was allowed

The gate passed because the system demonstrated strategic decision-basis improvement while simultaneously preserving:

- zero Purpose loading for irrelevant trivial work;
- bounded one-read strategic access;
- bounded 16 KiB context size;
- exact scope isolation;
- ordinary-task continuity when Purpose is unavailable;
- OS projection authority;
- no stale Purpose substitution.

That combination satisfied the architecture law: **Purpose Context had to prove user value before feature expansion.**
