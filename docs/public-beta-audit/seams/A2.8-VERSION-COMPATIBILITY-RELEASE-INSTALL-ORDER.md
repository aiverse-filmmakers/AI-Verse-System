## 3. Release authority model

The current release model has three distinct truth classes.

### Component current source

Each component repository may have accepted work newer than a frozen system release.

That source is not automatically installable as a composed Agent set.

### Distribution release set

Distribution is the executable composition authority.

A release set binds:

- one release ID;
- one profile;
- exact Git repository;
- exact 40-character commit SHA per component;
- install order;
- optional release-scoped dependency lock;
- compatibility entry;
- release evidence.

### System release/meta evidence

AI-Verse-System records architecture, accepted component/project evidence and system release status.

System metadata does not mutate Distribution release sets.

## 8. Custom profile compatibility

Custom composition is bounded to one admitted release set.

Distribution:

1. selects one exact release set;
2. validates requested components exist in that set;
3. closes declared dependencies inside that same set;
4. rejects components absent from the selected set.

It does not mix one component from a newer release candidate with another from an older set.

This is a strong fail-closed compatibility boundary.
