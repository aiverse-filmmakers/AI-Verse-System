## 4. Token truth semantics

Current money states are:

### ACTUAL

A trusted provider/runtime source supplied a real charge.

### CALCULATED

Authoritative usage was rated against a matching verified tariff.

### UNKNOWN

Evidence is insufficient for trusted money truth.

Verified laws:

- missing money is not zero;
- real zero remains ACTUAL zero;
- estimated usage cannot authorize CALCULATED;
- ambiguous model/route identity fails closed;
- stale current pricing cannot authorize current calculated money;
- secondary catalog data cannot authorize pricing;
- historical usage resolves historical effective tariff;
- ACTUAL takes precedence over calculation;
- currencies are retained rather than silently mixed.

These semantics are sound.

## 8. ACTUAL monetary-source defect

Token contains a correct trusted actual-cost source registry.

Trusted built-in source classes include provider/runtime-specific real-charge sources.

However, the canonical usage ingest boundary does not require all `actual_charge` values to pass through that registry.

A generic collector/direct caller can submit a syntactically valid real-charge object and the cost engine will classify it ACTUAL.

This remains existing HIGH finding:

`WSA-2026-024`

A2.7 confirms it is the central current monetary-authority defect.

## 9. Pricing batch atomicity

Pricing snapshots are individually immutable and source authority is registry-controlled.

However, one source refresh may write multiple snapshot files sequentially.

If a later write in the batch fails after earlier files were committed, the refresh is reported failed while a subset of the response can remain readable as immutable pricing evidence.

This remains existing MEDIUM finding:

`WSA-2026-025`

No duplicate finding is opened.

## 10. Pricing freshness and provenance

Current positive controls include:

- effective-dated snapshots;
- source-class registry;
- exact source identity stamped by trusted synchronizer;
- same-day freshness for current calculated cost where required;
- ETag/content-digest continuity for not-modified freshness renewal;
- stable error codes;
- no raw exception/credential text stored in pricing error state.

No cross-component source can silently select its own Token pricing authority.

## 11. Token read projection privacy

Default JSON/Gateway/MCP projections remove:

- raw source record IDs;
- source fingerprints;
- provider external-charge IDs.

Raw provenance export requires explicit opt-in.

Canonical usage rows contain no:

- prompt;
- response content;
- credential columns.

This keeps ordinary Token projections from becoming a hidden prompt/secret store.

## 17. Connections effect receipts

Connections uses append-only idempotency reservations and terminal effect receipts.

Ordinary receipt/list paths do not intentionally include secret values.

Successful/provider-error terminal receipts replay rather than externally re-execute.

Connections credentials stay behind opaque handles and adapter injection.

Current relevant defects remain:

- `WSA-2026-031`: cross-origin credential-handle isolation bypass on reauth;
- `WSA-2026-032`: component lifecycle/rate budget not fully rechecked at final provider edge;
- `WSA-2026-033`: normalized path authorization bypass.

These are final-edge authority defects, not receipt ownership defects.

## 18. Final-edge budgets

Connections' documented authority intersection includes current rate/call budgets.

Implementation checks usage budget before idempotency reservation but does not re-read the complete current budget after the final-edge boundary.

Concurrent different idempotency keys can observe the same remaining budget.

This remains `WSA-2026-032`.

Multiple Bots and Gateway operational budgets are local execution controls and are not converted into canonical Token pricing truth.

## 21. Cross-side contradictions

**Finding:** existing `WSA-2026-024`.

### C-A2.7-002 - failed pricing batch vs immutable usable snapshot subset

A refresh is recorded failed, but earlier snapshot files written before a later failure can remain usable pricing evidence.

**Finding:** existing `WSA-2026-025`.

### C-A2.7-003 - Connections current budget law vs final-edge implementation

Connections documents current rate/call budget as part of final authority, but does not recompute it immediately before provider effect.

**Finding:** existing `WSA-2026-032`.

### C-A2.7-004 - Distribution sanitized diagnostics vs raw ProcessError message

Distribution sanitizes explicit stdout/stderr but raw child output can survive in the top-level failure message.

**Finding:** existing `WSA-2026-036`.
