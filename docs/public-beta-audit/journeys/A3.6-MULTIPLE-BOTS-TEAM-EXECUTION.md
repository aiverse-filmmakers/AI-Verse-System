## 21. Existing generic Worker workspace defect

A1/A2 also proved:

`WSA-2026-023` - HIGH.

The managed Team Run path correctly binds Worker/Task/run/workspace.

However generic Worker coordination paths do not apply the same invariant before persistence.

A foreign-workspace Worker can receive persisted coordination state before the runner rejects execution, and failure handling can mutate that Worker's canonical status.

Direct Worker messaging has a related workspace-validation weakness.

Therefore the managed Team Run path passes, but the broader supported Worker surface is not fully isolated.
