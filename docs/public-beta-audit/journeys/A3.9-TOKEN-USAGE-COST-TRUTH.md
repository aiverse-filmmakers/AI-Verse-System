## 11. WSA-2026-024 monetary-authority defect

Token's truth law says ACTUAL must come from trusted monetary evidence.

But:

- usage protocol accepts a syntactically valid `actual_charge`;
- CollectorRunner verifies collector identity/version/runtime but does not require trusted actual-cost-source proof;
- direct ledger ingestion can persist that event;
- CostEngine prioritizes attached actual charge as ACTUAL.

Therefore an over-privileged/buggy collector can promote untrusted monetary input into canonical ACTUAL truth.

This remains:

`WSA-2026-024` - HIGH.

## 15. WSA-2026-025 pricing-batch defect

One pricing refresh may produce multiple immutable snapshots.

Current batch publication is sequential.

If a later snapshot write fails after earlier files were committed:

- refresh result can be marked failed;
- earlier new snapshots can remain visible/readable;
- CostEngine can use those visible snapshots.

Therefore a failed source refresh can still change available CALCULATED pricing evidence.

This remains:

`WSA-2026-025` - MEDIUM.

A3.9 does not duplicate it.
