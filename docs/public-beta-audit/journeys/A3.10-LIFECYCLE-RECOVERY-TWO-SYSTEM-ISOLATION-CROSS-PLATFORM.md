## 11. OS update/reinstall safety

## 14. Skills recovery

Skills uses immutable generations.

Normal update/learning:

1. stages a new generation;
2. verifies it;
3. commits immutable bytes;
4. atomically switches the active pointer.

Rollback restores a prior generation rather than editing old generation bytes.

Exact-head cross-platform Skills evidence includes update, rollback, uninstall preservation and recovery.

Open recovery/lifecycle findings remain:

- `WSA-2026-016` BLOCKER path containment;
- `WSA-2026-017` age-only stale-lock reclaim can overlap a live lifecycle holder;
- `WSA-2026-018` retention can remove a generation still pinned by a live execution.

A3 requires a real two-system A/B isolation journey.

6. writes distinct Data records in both;
7. creates distinct Bots/Tasks in both;
8. creates distinct Automations in both;

11. proves Context Ladder/Memory exact-source cannot cross systems;
12. proves Data/Worker/Automation owner requests cannot cross systems;
13. disables/restarts/uninstalls/reinstalls one system while the other remains ready and unchanged;
14. repeats after process restart;
15. runs on Ubuntu, macOS and Windows.
