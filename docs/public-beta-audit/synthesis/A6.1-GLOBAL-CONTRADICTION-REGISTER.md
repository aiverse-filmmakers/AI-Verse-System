## 5. Deduplication law

A6.1 uses the following rules.

### 5.1 Stable finding ID is the canonical unresolved contradiction family

When multiple source contradiction rows cite the same stable finding ID, they are **additional evidence/impact observations of the same unresolved family**, not separate defects.

Example:

`WSA-2026-008` is re-observed through repository concurrency, seam idempotency, Gateway chat/run control, Automations replay and adversarial concurrency. Those observations remain separately traceable but count as one unresolved global contradiction family.

### 5.2 Multi-finding source rows remain cross-cutting evidence

Rows such as `C-A4.1-003` intentionally summarize several already-distinct findings.

They are cited under every affected finding but do **not** merge those findings into one.

Whether multiple findings share a deeper common root cause belongs to A6.2.

### 5.3 Non-material contradictions remain historical evidence

A contradiction classified as verified, intentional compatibility, explicitly superseded, historical-only, bounded evidence or a resolved evidence discrepancy remains in the source ledger but is excluded from the unresolved global count.

### 5.4 No renumbering

No source contradiction or finding ID is changed.

The deduped register is an index over the published evidence, not a rewritten history.
