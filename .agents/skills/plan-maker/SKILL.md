This is a discovery route to the existing method and template, not a second planning method.

## Inputs and source

Use the requested project/scope, desired behavior and current implementation evidence. Within the active project, read `docs/PLAN-MAKER.md` for a System checkout, or `knowledge/implementation-planning/PLAN-MAKER.md` for a personal OS. Read the linked method and use its template proportionally. Respect the project's normal scope and source-authority rules.

## Routing

For creating, reviewing or refining software implementation plans, follow that method. For a request about an existing named plan, retrieve that plan rather than replacing it. Producing a plan does not itself authorize implementation, tests, issue publication or external actions.
